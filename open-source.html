Despliegue Instantáneo con Docker

¿Qué pasa cuando lo instalas en tu computadora?

En menos de 5 minutos levantas en tu propia laptop o servidor privado todo el stack completo: FastAPI + Ollama (LLM Local) + Qdrant Vector DB + Evolution WhatsApp API + Interfaz Web.

lifextreme-os-installer — bash
root@server:~# curl -sSL https://www.lifextreme.store/install.sh | bash
1

Abre tu Terminal

En Windows abre PowerShell (con Docker Desktop activo). En Mac o Linux abre la app Terminal.

2

Ejecuta el Instalador

Pega el comando de arriba. Descargará automáticamente los contenedores de IA, la base Qdrant y el servidor FastAPI.

3

Conecta tu Agencia

Abre http://localhost:8000, escanea tu QR de WhatsApp Business y sube tus tarifarios en PDF.
