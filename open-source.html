El Cerebro IA para tu Agencia.
Sin Pagar Suscripciones.

Descarga Lifextreme OS e instala un vendedor experto de Inteligencia Artificial que trabaja 24/7. Olvídate de pagar por mensaje a Meta, ChatGPT o Claude. Todo funciona de forma privada en tu propia computadora.

¿Qué hace este sistema por tu negocio?

Las 4 herramientas de nuestro stack tecnológico explicadas de forma sencilla.

El Cerebro
(Ollama + DeepSeek)

En lugar de pagar mensualmente a OpenAI (ChatGPT) por cada mensaje, instala modelos de IA avanzados directamente en tu computadora de forma local y privada.

Impacto: $0 costos de facturación por mensajes.

La Memoria
(Qdrant Vector DB)

Una base de datos vectorial que lee tus tarifarios, PDFs y manuales operativos para que la IA responda usando exclusivamente tu información real.

Impacto: 0% riesgo de vender tours inexistentes.

Atención Masiva
(Evolution API)

Conecta tu propio número de WhatsApp Business al cerebro de la IA sin tener que pagarle a Meta por "conversación iniciada" ni usar proveedores caros.

Impacto: Atiende a miles de turistas simultáneamente.

CRM Integrado
(Supabase)

Gestiona tus reservas, perfiles de turistas y datos de ventas en una base de datos relacional ultrarrápida (PostgreSQL). Reemplaza a CRMs costosos.

Impacto: Centraliza la gestión comercial sin mensualidades.

El Enrutador
(LiteLLM)

Permite a tu agencia saltar entre IAs gratuitas (DeepSeek) o de pago (OpenAI/Groq) con 1 clic si tu computadora no tiene suficiente potencia.

Impacto: Flexibilidad total sin depender de un proveedor.

Buscador Privado
(SearxNG)

Le da acceso a internet en tiempo real a tu IA (para revisar el clima, estado de vuelos, paros o protestas) sin pagar costosas APIs de Google.

Impacto: Cotizaciones precisas basadas en el internet de hoy.

El Motor Lógico
(FastAPI)

El director de orquesta que conecta WhatsApp, la base de datos y la IA. Diseñado en Python para ser el más rápido del mercado backend.

Impacto: Procesamiento instantáneo sin demoras para el cliente.

El Instalador Mágico
(Docker Compose)

Todo el ecosistema descrito arriba es extremadamente complejo de instalar para un no-programador. Docker empaqueta estas gigantescas herramientas en una sola "caja lista para usar".

Impacto: Lo que tardaría semanas en configurarse por un ingeniero DevOps, se instala en tu computadora con 1 solo comando.

Instalación en 1 Clic

Descarga el código fuente directamente desde nuestro repositorio público.

v2.0 Stable

Pasos para instalar:

  1. Asegúrate de tener Docker Desktop instalado en tu computadora (Windows/Mac/Linux).
  2. Abre tu terminal (Símbolo del sistema o PowerShell).
  3. Copia el código que ves abajo y pégalo en la terminal. Presiona Enter.
  4. El sistema descargará la base de datos, el cerebro y el panel de control automáticamente.
$ curl -sSL https://raw.githubusercontent.com/lifextremeperu/Lifextreme-Web-AI/main/install.sh | bash
¡Comando de instalación copiado!
